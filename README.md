# Intelligent Discovery / 智能发现

> 从可信信息、真实经验和可追溯证据中，发现世界变化，理解它们，并做出更好的判断。

Intelligent Discovery 不是替人下结论的聊天机器人，也不是把网页列表换一种形式展示的搜索工具。它是一套开源的知识发现系统：帮助你看见正在发生的重要变化，找到相关案例与经验，理解证据、限制和未知项；最终判断始终由人完成。

本项目采用 [Apache License 2.0](LICENSE)。欢迎使用、研究、改进和贡献，但请始终尊重来源、许可证、隐私和证据边界。

## 用一句话理解它

**发现世界 → 查看来源与证据 → 连接案例与知识 → 了解限制与风险 → 继续探索或提交反馈。**

我们希望它每天都能帮助用户回答两类问题：

- “今天有什么值得我理解的新变化？”
- “面对这个问题，哪些可靠经验、证据和未知项能帮助我判断？”

## 当前处于什么阶段？

当前为 **v0.9.6 Web Beta Release Candidate**：核心领域、治理、体验与扩展边界已经建立，项目可供开发者、本地测试者和早期协作者试用与审阅。它还不是公开生产服务，也尚未提供完整 Web 页面、账户认证、联网世界来源或自动推荐。

这一区分很重要：我们不会把“规划中”“候选内容”或“测试契约”包装成已经开放的能力。

## 现在可以做什么

- 创建发现任务，记录问题、来源、证据、发现、风险、建议与未知项。
- 将可审计发现沉淀为知识，并生成 Markdown 报告。
- 管理案例、版本历史、验证状态及跨任务关联。
- 探索概念、关系、分类、标签与本地知识资产。
- 使用世界发现、内容宇宙、趋势、新鲜度和 Discovery Stream 的领域基础；所有世界事件候选必须经过验证。
- 提交结构化反馈、问题、案例线索和开发者联系请求，并进入可追踪的人工治理流程。
- 审阅数据保护、备份恢复、发布门禁、受控进化和生态扩展接口。

## 我们明确不做什么

- 不替用户自动做投资、医疗、职业、商业或其他最终决策。
- 不把 AI 推测、来源登记或候选内容伪装成已验证事实。
- 不读取私人聊天、私人搜索正文、私人知识或未经授权的用户行为。
- 不开放黑箱推荐、自动改写知识、自动修改权限/信誉/规则，或自动处罚用户。
- 不提供 iOS 或 Android App；移动端是独立的未来阶段。

## 为什么值得参与

很多信息产品追求更多内容和更长停留时间。Intelligent Discovery 更关心“发现价值”：它是否帮助你理解、继续探索、解决问题或贡献可靠经验。

你可以作为：

- **探索者**：提出问题、浏览发现、保存有价值的方向、指出不清楚之处；
- **贡献者**：提交来源、案例、故事、经验或修正线索；
- **专家协作者**：补充证据、背景、适用边界和限制；
- **开发者**：改进开放代码、接口、测试和可观测性。

任何贡献都不会直接改写核心知识。它会经历来源、证据、审核、治理和版本记录流程。

## 信任如何被保护

```text
公开来源 → 候选内容 → 证据 → 人工验证 → 已发布发现
                                      ↓
用户反馈 → 问题分析 → 改进提案 → 受控实验 → 人工批准 → 再次验证
```

- 每项重要结论应关联来源、证据、置信度、限制和未知项。
- 候选案例、候选世界事件和精选内容不等于已验证知识。
- 个人兴趣必须由用户明确确认，并可查看、修改、删除。
- 数据导出、删除、审计、授权撤销、备份恢复和发布审批均有明确边界。
- 自动化只能提出信号、候选或提案；重要改变必须由人审核。

详见 [信任、治理与演进基础](docs/TRUST_GOVERNANCE.md) 与 [Beta 体验智能](docs/BETA_EXPERIENCE_INTELLIGENCE.md)。

## 快速开始（开发者）

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
uvicorn intelligent_discovery.api:app --reload
```

打开 `http://127.0.0.1:8000/docs` 试用当前 API。默认本地数据库位于 `data/intelligent_discovery.db`；可通过 `ID_DATABASE_PATH` 覆盖。请不要把测试 API 误当作公开生产服务。
