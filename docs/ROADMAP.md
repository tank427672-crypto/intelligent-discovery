# 开发路线

## v0.1 — Evidence-led Discovery Core（当前）

目标：验证从问题到可追溯报告的最小闭环。

完成：任务编排、资料登记、发现/风险/建议/未知项、知识沉淀、报告、HTTP API、SQLite 实现。

非目标：自动联网研究、用户账户、自动决策、社区发布。

## v0.2 — Research Intelligence Foundation（完成）

完成：来源智能、Evidence、人工反馈、引用式报告、研究提供器契约和结构化失败语义。

未完成：真实研究提供器、来源去重、工作空间、身份和审计。它们进入后续迭代，前提是许可与数据治理决策完成。

## v0.3 — Knowledge + Case Intelligence Foundation（完成）

完成：案例知识资产、来源/证据/发现关联、验证和生命周期、版本历史、跨任务引用、案例报告引用及未来案例插件契约。

未完成：全局案例检索、案例索引、现实更新执行器与可解释选项比较。任何未来决策建议仍必须显示依据、局限、置信度和人工复核状态。

## v0.9.1 — Beta Release Preparation + Case Showcase Foundation（完成）

完成：20 条可追溯来源的案例候选、前端无关的案例展示契约、受邀测试用户模型、反馈提交与治理分诊、发布候选/人工批准清单，以及隐私安全的 Beta 事件记录。

未完成：逐条案例验证和正式导入、真实身份认证、公开社区、积分体系、生产部署和 Public Beta。候选不得当作已验证知识展示。

## v0.9.2 — Trust Foundation + Private Beta Operations（完成：RC 准备基线）

完成：受控 RC 状态机、信任检查、私有数据查看/导出/删除审计契约、隔离备份恢复演练、Beta 协议/同意/退出模型、案例发布审核清单、运营分级、进化日历和 Beta 指标模型。

完成：独立 Communication Intelligence Foundation，支持私有沟通、反馈闭环、受控求助/贡献、AI 输出解释与元数据风险治理。

未完成：生产认证、加密/密钥管理、真实部署迁移、持久化 Release 审批、受控邀请工作流、逐案审核完成及公开 Beta；因此当前仍不是可直接公开发布的候选版本。

## v0.9.3 — Private Beta Experience Intelligence（完成：运行反馈准备基线）

完成：经同意的最小化体验信号、结构化用户反馈工作流、P0–P3 分诊、与改进提案/受控实验的关联、专家增强和帮助质量评价契约、周期复盘指导。

未完成：真实用户运营数据、实际趋势聚合、邀请运营、生产安全控制和完整 Beta Review 报告实例。不得把当前测试模拟当作真实用户验证。

## v0.9.5 — World Intelligence Acquisition Foundation（完成：领域基础）

完成：公共来源登记、Connector Port、候选事件、人工验证边界、新鲜度、趋势与 Feed 输入契约。

未完成：真实连接器、数据抓取、后台调度、持久化、Feed UI、推荐算法和真实世界事件数据。候选始终不等于已验证知识。

## v1.0 — Governed Ecosystem

目标：经过治理评审后，逐步开放个人智能、推荐、机会雷达、社区贡献、企业服务和第三方扩展。

退出标准：稳定扩展 API、公开安全与隐私承诺、版本兼容政策、社区治理与可观测性到位。
