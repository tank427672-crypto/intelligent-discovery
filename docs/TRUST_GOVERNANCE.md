# Trust + Governance + Evolution Foundation（v0.6）

`DataVisibility` 区分 private、shared、public。私人对象不能直接变为公开，必须先明确共享并走人工审核；治理与审核均单独留痕。当前仅建立模型和记录，不处理真实账户、身份或网络发布。

系统反馈与知识反馈分离：`SystemFeedback` 评价功能，`FeaturePerformance` 汇总使用、满意度和低评分模式。`ImprovementProposal` 只记录人工可审查改进建议；`EvolutionExperiment` 只能基于已批准提案开始，绝不自动改代码或知识规则。

网络层、社区审核、贡献者信任和企业权限仍为预留能力。接入前必须完成身份、版权、隐私、删除权和审计策略。
